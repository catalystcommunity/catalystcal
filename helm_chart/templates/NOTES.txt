No HTTPRoute or Ingress is enabled. To open catalystcal from your workstation:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "catalystcal.fullname" . }}-web {{ .Values.service.web.port }}:{{ .Values.service.web.port }}
  then open http://localhost:{{ .Values.service.web.port }}
{{- end }}

Public paths: /api/* and /ics/* go to the API. Everything else goes to the web UI.
Calendar apps fetch /ics/<token> without a session, so /ics must be public.

API health:
  kubectl -n {{ .Release.Namespace }} port-forward deploy/{{ include "catalystcal.fullname" . }}-api {{ .Values.api.opsPort }}:{{ .Values.api.opsPort }}
  curl http://localhost:{{ .Values.api.opsPort }}/readyz

The API is ONE pod with SQLite on a ReadWriteOnce volume (strategy Recreate).
Each upgrade has a short API outage. Do not scale the API Deployment.

WARNING: api.persistence.enabled is false. The database is on an emptyDir and
is lost when the pod goes away.
{{- end }}
